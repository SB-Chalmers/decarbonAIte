# Research context

## decarbonAIte

[The Chalmers project record](https://research.chalmers.se/en/project/10568) describes **decarbonAIte**: machine learning for urban digital twins and renovation decision support combining energy, carbon and cost assessment. The preserved files cover the renovation LCA/LCC workflow within that wider research.

[Vinnova's completed-project record](https://www.vinnova.se/p/decarbonaite/) gives **October 2021–April 2025**, grant **2021-02759**, with **Stiftelsen Chalmers Industriteknik** as coordinator. Chalmers lists **2021–2024** for its funded participation.

Chalmers names **Alexander Hollberg** as contact and **Alex Arnoldo Gonzalez Caceres** as participant, in Architecture and Civil Engineering, Building Technology. Listed collaborators are **Asymptotic AB**, **Innovatum**, **Sinom AB** and **Stiftelsen Chalmers Industriteknik**.

These are project roles. The original workflow documentation credits **Jacob Forsberg** as software author (July 2023); [CITATION.cff](../CITATION.cff) preserves that credit. Current maintainers and any further software authors remain to be confirmed.

## Related project publication

The project record lists [*Application and validation of a method to assess the energy reduction and environmental impact of renovation alternatives* (2023)](https://research.chalmers.se/en/publication/536967), [DOI: 10.1088/1755-1315/1196/1/012104](https://doi.org/10.1088/1755-1315/1196/1/012104). Its authors are Alex Arnoldo Gonzalez Caceres, Sanjay Somanath, Jacob Forsberg, Alina Galimshina, S. Theißen and Alexander Hollberg.

The paper describes a Rhino/Grasshopper/EnergyPlus renovation assessment with an Uddevalla case study and explicitly links to the funded project. It provides related methodological context; a project member should confirm the exact correspondence between the published implementation and this preserved workflow before treating this repository as the paper's reproducibility package.
